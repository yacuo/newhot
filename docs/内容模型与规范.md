# 内容模型与规范

配置放 `config/`，内容放 `data/`，构建期读取，不走数据库。字段以代码里的 schema 为准。

## 目录结构

```text
config/                      站点配置（结构见「频道与分类」「页面配置」）
├── channels/<channel>.json  频道 + 二级分类
├── tutorials/               教程页配置与 catalogs/
├── update-log/              更新日志页配置
├── home/ about/ open-source/ themes/   页面文案
└── site.json content-types.json sources.json search.json

data/                        内容
├── channels/<channel>/<subcategory>/posts/<slug>.md
├── tutorials/<tutorialId>/articles/<slug>.md
├── update-log/posts/<slug>.md
└── vendors/                 公司、主题、发展史与公司 SEO
```

## 频道与分类

`config/channels/<channel>.json`：

| 字段 | 说明 |
| --- | --- |
| `label` / `labelEn` | 展示名 |
| `description` | 频道简介 |
| `seo` | `{ title, description }` |
| `faqs` | 可选，频道页 FAQ |
| `standards` | 可选，频道写作标准 |
| `order` | 排序，数字小的在前 |
| `subcategories` | 二级分类数组，每项包含 `id`、`label`、`description`、`seo`、`order` |

分类 id 写在 `subcategories[].id`；文章 URL 为 `/{subcategory}/{slug}/`，文章文件放在 `data/channels/<channel>/<subcategory>/posts/`。

## 文章 frontmatter

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `title` | string | 必填；文章标题 |
| `slug` | string | 必填；小写英文、数字、连字符；与文件名一致 |
| `description` | string | 必填；页面描述 |
| `date` | YYYY-MM-DD | 必填 |
| `time` | HH:MM | 可选；时间轴排序 |
| `updated` | YYYY-MM-DD | 可选；缺省按 `date` |
| `author` | string | 可选 |
| `company` | string | 可选；取自 `data/vendors/companies.json` 的公司 id |
| `product` | string | 可选；该公司 `products[].id` |
| `source` | URL | 可选；单一来源链接 |
| `category` | string | 必填；频道 id |
| `subcategory` | string | 频道文章必填；决定文章 URL |
| `type` | enum | 可选；见 `config/global/content-types.json` |
| `tags` | string[] | 标签 |
| `faqs` | `{question, answer}[]` | 可选；页面 FAQ 区块 |
| `glossary` | `{term, definition}[]` | 可选；术语区块 |
| `sources` | `{title, url, publisher?, accessedAt?}[]` | 可选；来源列表 |
| `draft` | boolean | `true` 不构建 |
| `status` | `draft`/`reviewed`/`published` | 可选；自动化导入时用于标记状态 |
| `sourceId` / `fetchedAt` / `contentHash` | string | 可选；自动化导入时的溯源字段 |
| `generator` | `{provider, model, prompt}` | 可选；标记内容由什么工具生成 |

## 教程

`tutorials/<tutorialId>/catalog.json`：

| 字段 | 说明 |
| --- | --- |
| `order` | 排序 |
| `title` / `description` | 系列名称与简介 |
| `type` | `ai` / `frontend` / `backend` / `data` |
| `author` / `source` | 作者与参考来源 |
| `publishedAt` / `updatedAt` | 发布日期与更新日期 |
| `icon` | `book` / `code` / `spark` / `route` |
| `gradient` | `{ from, to }` |
| `introBlocks` | `{ title, description }[]` |
| `sections` | `{ title, description?, icon?, articles[] }[]` |
| `faqs` | 可选 |

`sections[].articles` 可以写 slug 字符串，也可以写对象：

```json
{ "href": "how-it-works", "sidebarTitle": "短标题", "badge": "可选" }
```

`href` 也可以直接写外部链接，此时该条目在新窗口打开。

教程文章放在 `tutorials/<tutorialId>/articles/<slug>.md`，frontmatter 必填 `title`、`slug`、`description`、`date`、`category`；`tags`、`faqs`、`author` 可选。正文不写 H1，标题由页面模板渲染；最后一个 H2 用「小结」或「总结」收尾。

## 更新日志

```text
data/update-log/page.json          # 列表页文案
data/update-log/seo.json           # 列表页 SEO
data/update-log/posts/{slug}.md    # 一条日志一个文件，文件名即 slug
```

`posts/*.md` 的 frontmatter：

| 字段 | 说明 |
| --- | --- |
| `date` | YYYY-MM-DD |
| `version` | `vX.Y.Z` |
| `title` | 4–80 字 |
| `summary` | 20–200 字 |
| `tags` | 1–5 个 |
| `added` / `improved` / `fixed` | 至少一类，每条 4–120 字 |

schema 用 `strictObject`，多写或拼错字段都会在构建期报错。

## 静态页数据

`home`、`about`、`open-source`、`themes` 四个目录各含若干 JSON，由 `src/entities/page-content/model/*.ts` 声明对应 schema 后读取：

- 目录里所有 JSON 都必须被 TS 声明，否则构建失败
- 缺文件同样失败
- 页面级 SEO 统一为 `{ title, description, path }`

## 新增频道 / 分类

1. 新建 `config/channels/<channel>.json`，在 `subcategories` 里补分类
2. 文章放在 `data/channels/<channel>/<subcategory>/posts/`
3. 在 `config/global/content-types.json` 的 `defaults` 中补默认 `type`
4. 跑 `npm run build` 确认页面正常生成
